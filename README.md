# A Sparse Matrix Multiplication Accelerator (SPARM + MAERI-Inspired Architecture)

A configurable sparse matrix multiplication accelerator inspired by the **SPARM** and **MAERI** architectures, designed for efficient GEMM and future SpGEMM acceleration through flexible dataflow execution, hierarchical routing networks, and reconfigurable reduction structures.

This project focuses on implementing and studying modern accelerator architectures for sparse linear algebra and AI workloads using cycle-accurate hardware modeling and Verilog/SystemC-based design exploration.

---

# Overview

Sparse matrix multiplication is a core operation in:
- Machine Learning
- Deep Neural Networks
- Scientific Computing
- Graph Processing
- Sparse Linear Algebra

Traditional dense accelerators suffer from:
- Irregular sparsity patterns
- Low PE utilization
- Memory bandwidth bottlenecks
- Inefficient data movement

This project implements a configurable accelerator architecture inspired by:
- **SPARM**
- **MAERI**
- Flexible multi-dataflow sparse accelerators

The architecture supports:
- Reconfigurable dataflow execution
- Hierarchical multicast distribution
- Parallel multiplication
- Configurable reduction trees
- Virtual neuron mapping
- Future sparse SpGEMM extensions

# System Architecture

```text
Input Matrices
      ↓
Controller & Scheduler
      ↓
Distribution Network (DN)
      ↓
Multiplier Network (MN / mSwitch Array)
      ↓
Reduction Network (RN)
      ↓
Output Matrix / Partial Sums
```

The architecture consists of three major hardware subsystems:

## 1. Distribution Network (DN)

Handles multicast and routing of input data to processing elements.

## 2. Multiplier Network (MN)

Performs parallel multiplication using configurable mSwitch units.

## 3. Reduction Network (RN)

Accumulates and merges partial sums through reduction switches.

---

# Key Components

# 1. Distribution Network (DN)

The DN is responsible for:
- High-bandwidth data multicasting
- Flexible virtual neuron mapping
- Non-blocking routing
- Adaptive data distribution

## Features
- Chubby-tree topology
- Local forwarding links
- Static routing configuration
- Sparse-friendly dataflow support

## Core Building Block
- Simple Switch (SS)

---

# 2. Multiplier Network (MN)

The MN performs parallel multiplication using configurable **Multiplier Switches (mSwitches)**.

## mSwitch Features
- Activation FIFOs
- Weight FIFOs
- Partial sum forwarding
- Configurable routing behavior
- Parallel MAC execution
- Sparse-aware operation

## Supported Operations
- Multiply
- Forward psums
- Idle/skipping for sparse entries

---

# 3. Reduction Network (RN)

The RN combines partial sums generated by the MN.

## Reduction Modes
- Accumulate
- Merge
- Bypass

## Components
- Single Reduction Switch (SRS)
- Double Reduction Switch (DRS)

The RN enables scalable reduction trees for efficient accumulation across multiple processing elements.

## 1. Configuration Phase
The controller configures:
- Virtual neurons
- Routing paths
- Multiplier network behavior

Input activations and weights are distributed through the DN.

## 3. Parallel Multiplication
mSwitch units perform:
- MAC operations
- Partial sum generation
- Sparse-aware forwarding

## 4. Reduction
The RN accumulates and merges partial sums into final outputs.
